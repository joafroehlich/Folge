Ist g Grenzwert? Überprüfen Sie dies anhand 
der Differenzenfolge an - g. 

         3n - 2
a) an = --------, g = 3
         n + 2

         n2 + n
b) an = --------, g = 0,2
           5n2  

g ist dann Grenzwert der Folge an, 
wenn an - g eine Nullfolge ist.

a)
 
      3n - 2
an = --------
       n + 2

   a1     a2     a3     a4     a5
  0,33    1     1,4    1,67   1,86   
         
 3n - 2         3n - 2 - 3 * (n + 2)
-------- - 3 = ---------------------- = 
  n + 2                 n + 2
  
       8
= - ------- geht gegen 0 für n gegen ∞.  
     n + 2

g = 3 ist Grenzwert.

b)

      n2 + n
an = ---------
        5n2  

 a1     a2     a3     a4     a5
0,4    0,3    0,27   0,25   0,24

 n2 + n            n2 + n - n2
--------- - 0,2 = ------------- = 
    5n2                 5n2
    
    1   
= ---- geht gegen 0 für n gegen ∞.    
   5n

g = 0,2 ist Grenzwert.

Untersuchen Sie die Folgen für n ∈ ℕ auf 
Beschränktheit:

           n    
a) an = -------
         n + 2

           1  
b) an = - ---
           n 

a)

        n    
an = -------
      n + 2

 a1     a2     a3     a4     a5
0,33    0,5    0,6   0,67    0,71

Vermutung: 1 ist obere Schranke.  

        n         
1 > -------- |*(n + 2)
     n + 2            

 n + 2 > n |-n

2 > 0 ist eine wahre Aussage 

--> Vermutung stimmt: 1 ist obere Schranke.

--> Vermutung: 0 ist untere Schranke

        n         
0 < -------- |*(n + 2)
      n + 2            

0 < n ist eine wahre Aussage 

--> Vermutung stimmt: 0 ist untere Schranke.

--> an ist beschränkt.

b)

        1  
an = - ---
        n 

 a1     a2     a3     a4     a5
-1    -0,5   -0,33  -0,25   -0,2

Vermutung: 0 ist obere Schranke.  

       1         
0 > - --- |*n
       n             

 0 > - 1 ist eine wahre Aussage 

--> Vermutung stimmt: 0 ist obere Schranke.

Vermutung: -1 ist untere Schranke

        1         
-1 ≤ - --- |*n 
        n             

-n ≤ 1 ist eine wahre Aussage 

--> Vermutung stimmt: -1 ist untere Schranke.

--> an ist beschränkt.

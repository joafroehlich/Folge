Aufgabe 50

Bestimmen Sie die explizite Darstellung der 
Folge an, wenn die rekursive Darstellung gegeben
ist. 

a) a1 = 2, an+1 = an + 0,5    

b) a1 = 1, an+1 = 2an - 3 

a)

Zahlenfolge: 2; 2,5; 3; 3,5; 4 ...

2 = 1 * 0,5 + 1,5 = 2

2,5 = 2 * 0,5 + 1,5

3 = 3 * 0,5 + 1,5

3,5 = 4 * 0,5 + 1,5

4 = 5 * 0,5 + 1,5

an = n * 0,5 + 1,5

es handelt sich um eine arithmetische Folge mit d = 0,5

an = a1 + (n -1) * d

an = 2 + (n - 1) * 0,5

an = 2 + 0,5n – 0,5

an = 0,5n + 1,5

b)

Zahlenfolge: 1, -1, -5, -13, -29 ...

1 = 3 - 21 

-1 = 3 - 22

-5 = 3 - 23

-13 = 3 - 24

-29 = 3 - 25

an = 3 - 2n

Aufgabe 101

a) Fügen Sie zwischen die Zahlen 4 und 128 
4 Zahlen so ein, dass eine geometrische 
Zahlenfolge entsteht. 
b) Fügen Sie zwischen die Zahlen -200 und -6,25 
4 Zahlen so ein, dass eine geometrische 
Zahlenfolge entsteht.

a)

a1 = 4, a6 = 128

a6 = a1 * q5 

128 = 4 * q5 |:4

32 = q5 |5

q = 2

 a1      a2      a3      a4       a5      a6
 4        8      16      32      64      128 

b) 

a1 = -200, a6 = -6,25

a1 = a1 * q5 

-6,25 = -200 * q5 |:200

0,03125 = q5 |5

q = 0,5

   a1      a2      a3      a4       a5      a6
 -200    -100     -50     -25    -12,5   -6,25

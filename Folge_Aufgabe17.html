Aufgabe 17

Untersuchen Sie die Folgen für n ∈ ℕ auf 
Beschränktheit.

a) an = (-2)n

b) an = n2+1 - n

a)

an = (-2)n

 a1     a2     a3     a4     a5
 -2     4      -8     16    -32

Die Folge alterniert und ist divergent.

--> an ist nicht beschränkt.

b)

an = n2+1 - n

 a1     a2     a3     a4     a5
0,41   0,32   0,27   0,24   0,21

Vermutung: 0 ist untere Schranke.  

0 < n2+1 - n |+n

n < n2+1 - n |2
^
n2 < n2 + 1  ist eine wahre Aussage.

--> Vermutung stimmt: 0 ist untere Schranke.

Vermutung: 1 ist obere Schranke

1 > n2+1 - n |+n

1+n > n2+1  |2

n2 + 2n + 1 > n2 + 1 |-n2 - 1

2n > 0 ist eine wahre Aussage

--> Vermutung stimmt: 1 ist obere Schranke.

--> an ist beschränkt.

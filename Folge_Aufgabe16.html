         2n + 1

         3n - 1

           n2

a)

      2n + 1    
an = --------
      3n - 1

 a1     a2     a3     a4     a5
1,5     1    0,875   0,82   0,79

Vermutung: 1,5 ist obere Schranke.  

       2n + 1         
1,5 ≥ -------- |*(3n - 1)
       3n - 1            

 4,5n - 1,5 ≥ 2n + 1 |-2n + 1,5

2,5n ≥ 2,5 ist eine wahre Aussage 

--> Vermutung stimmt: 1,5 ist obere Schranke.

--> Vermutung: 0 ist untere Schranke

     2n + 1         
0 < -------- |*(3n - 1)
     3n - 1            

0 < 2n + 1 ist eine wahre Aussage 

--> Vermutung stimmt: 0 ist untere Schranke.

--> an ist beschränkt.

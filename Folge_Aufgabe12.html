Monotonie:

         2n
a) an = ------
        n + 1

        1 - n2

a)

       2n
an = ------
      n + 1

 a1     a2     a3     a4     a5            
 1     1,33    1,5   1,6    1,67

        2 * (n + 1)     2n + 2
an+1 = ------------- = --------
         n + 1 + 1       n + 2

             2n + 2      2n        
an+1 - an = -------- - ------- = 
              n + 2     n + 1
              
   (2n + 2) * (n + 1) - 2n * (n + 2)
= ------------------------------------
              (n + 2) * (n + 1)

             2n + 2       2n        
an+1 - an = --------- - ------ =  
              n + 2      n + 1         
              
   2n2 + 4n + 2 - 2n2 - 4n
= -------------------------
       (n + 2) * (n + 1)

                     2              > 0
an+1 - an = -------------------- = ------ = > 0 
             (n + 2) * (n + 1)      > 0

--> an+1 > an --> an ist streng monoton steigend
